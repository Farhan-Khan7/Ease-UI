## How to Run This Project Locally

Follow these steps to run Ease UI on your computer.

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/Farhan-Khan7/Ease-UI.git
```

This will download the project from GitHub to your computer.

### 2. Enter the Project Folder

After cloning, move inside the project folder:

```bash
cd Ease-UI
```

You can check that you are inside the correct folder by running:

```bash
dir
```

You should see files such as `package.json`, `src`, `public`, and `vite.config.ts`.

### 3. Install Dependencies

Install all the packages required by the project:

```bash
npm install
```

This reads the `package.json` file and installs the required dependencies inside the `node_modules` folder.

### 4. Start the Development Server

Run the project using Vite:

```bash
npm run dev
```

Vite will provide a local URL in the terminal. Open that URL in your browser to view the project.

### 5. Build the Project

To create the production build:

```bash
npm run build
```

### 6. Preview the Production Build

After building the project, you can preview it locally with:

```bash
npm run preview
```

### Quick Start

If you already have Node.js installed, you can run the project with just:

```bash
git clone https://github.com/Farhan-Khan7/Ease-UI.git
cd Ease-UI
npm install
npm run dev
```

> **Note:** Make sure you have **Node.js and npm** installed on your computer before running the commands above.
